
# Reflection

## 1. How did AI support the documentation process?

AI helped me organize the README into clear sections such as Overview, Installation, Example Usage, Inputs and Outputs. It also helped improve the wording and formatting of the R Markdown document.

However, AI-generated content needs to be reviewed because it may contain incorrect assumptions or code. I verified the R script by running it in RStudio and checked the R Markdown output by knitting the document.

## 2. How did you validate and improve the AI-generated content?

I reviewed the Markdown headings, bullet points, code blocks and project structure. I executed the R script and confirmed that it generated the expected sales summary and bar chart.

I also knitted the R Markdown document successfully and reviewed the generated HTML output. I improved the documentation to ensure that the README and R Markdown files describe the same project.

## 3. What ethical considerations should be followed when using AI?

AI usage should be disclosed clearly, including the tool, date and prompts used. AI-generated content should not be copied without reviewing and validating it.

Personal or confidential data should not be shared with AI tools. In this project, I used synthetic sales data only.

I remain responsible for the accuracy, originality and final quality of the assignment.
